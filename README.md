# NexaGrow Digital — Task 1

Responsive Company Website created for the WeIntern Full Stack Development Week 2 Task 1.

## Pages
- Home
- About
- Services
- Contact

## Technologies
- HTML5
- Tailwind CSS
- JavaScript ES6+
- Font Awesome
- Git/GitHub
- Chrome DevTools

## Important note
This version intentionally uses a single `index.html` file. The four required pages are implemented as separate page views/sections controlled by JavaScript navigation.

For a strict interpretation of the assignment's "four pages" requirement, these four views can later be split into:
`index.html`, `about.html`, `services.html`, and `contact.html`.

## Features
- Responsive navigation
- Mobile hamburger menu
- Responsive Flexbox/Grid layouts
- Consistent branding
- Professional footer
- Contact form
- Client-side form validation
- Responsive breakpoints
